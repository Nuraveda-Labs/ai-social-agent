# Changelog

## [0.1.0] — 2026-05-18

### Added

- Initial open-source release of the AI social agent engine.
- LangGraph scout → script → publish → ORM pipeline.
- Multi-platform publishers: YouTube Shorts, Instagram Reels, X, LinkedIn.
- Pluggable video generators (Kling, Veo, fal.ai).
- SQLModel async DB + Alembic migrations.
- FastAPI webhook receiver.
- Configurable per-brand × per-platform pacing.

### Removed (extracted to a separate proprietary repo)

- Brand directory.
- Fine-tuned caption + ORM-response prompts.
- Region/language-specific tone presets.
